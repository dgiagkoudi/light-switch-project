# Light Switch Project

Διαδραστική εφαρμογή που προσομοιώνει έναν διακόπτη φωτός με εφέ φακού, δυναμικές σκιές και λειτουργικό σχοινί για εναλλαγή μεταξύ Dark και Light mode.

## Λειτουργίες

- Εφέ φακού σε πραγματικό χρόνο που ακολουθεί τον κέρσορα
- Υποστήριξη Touch Events για κινητές συσκευές
- Διαδραστικό σχοινί με drag-and-drop λειτουργία
- Δυναμικές σκιές κειμένου που υπολογίζονται σε πραγματικό χρόνο
- Εναλλαγή Dark/Light mode
- Responsive σχεδιασμός για κινητές συσκευές
- Ομαλά visual transitions και animations

## Τεχνολογίες

- HTML5
- CSS3
- JavaScript (Vanilla)

## Τοπική Εκτέλεση

1. Clone repository

```bash
git clone https://github.com/dgiagkoudi/light-switch-project.git
cd light-switch-project
```

2. Εκτελέστε την εφαρμογή
Ανοίξτε το `index.html` απευθείας στον browser.

Για τη σωστή εμφάνιση των assets, βεβαιωθείτε ότι υπάρχει ο φάκελος `public` με όλα τα απαραίτητα αρχεία (PNG, JPG, MP3).

## Λειτουργικότητα

Η εφαρμογή επιτρέπει στους χρήστες να:

- Εναλλάσσουν μεταξύ dark και light mode
- Χρησιμοποιούν το σχοινί για έλεγχο του διακόπτη
- Αλληλεπιδρούν με το flashlight effect
- Βλέπουν δυναμικές σκιές που αντιδρούν στην κίνηση του κέρσορα
- Χρησιμοποιούν την εφαρμογή σε desktop και mobile συσκευές
