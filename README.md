# Light Switch Project

🇬🇷 Read this in [Ελληνικά](README_GR.md)

An interactive light switch simulation built with Vanilla JavaScript, featuring a realistic flashlight effect, dynamic text shadows, and an interactive pull-chain mechanism for switching between dark and light mode.

## Features

- Real-time flashlight effect following mouse movement
- Touch Events support for mobile devices
- Interactive pull-chain with drag-and-drop functionality
- Dynamic text shadows calculated in real time
- Dark/Light mode switching
- Responsive mobile layout
- Smooth visual transitions and animations

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## Local Setup

1. Clone repository

```bash
git clone https://github.com/your-username/light-switch-project.git

cd light-switch-project
```

2. Run project

Open `index.html` directly in your browser.

For proper asset rendering, make sure the `public` folder exists and contains all required files (PNG, JPG, MP3).

## Functionality

The application allows users to:

- Toggle between dark and light mode
- Drag the hanging chain to control the light switch
- Interact with the flashlight effect
- Experience dynamic shadows reacting to cursor position
- Use the application on desktop and mobile devices
